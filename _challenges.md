# React useState Practice Tasks

## Instructions

Solve the following tasks using **React** and **useState** only.

---

### 1. Change Color

Create a `div` with background `bg-green-600` and a button.
When clicking the button, change the color to `bg-red-700`.

---

### 2. Counter +

Create a number starting from `0` and a button `+`.
Each click increases the number by 1.

---

### 3. Counter + / −

Create a number starting from `10` and two buttons:

* One increases
* One decreases

---

### 4. Show / Hide Text

Create a button and text **Hello**.
When clicking the button:

* show text
* click again → hide text

---

### 5. Toggle Button Text

Create a button with text **ON**.
When clicked → change to **OFF**
Click again → return to **ON**

---

### 6. Background Toggle

Create a page with background `bg-white`.
When clicking a button → background becomes `bg-black`.

---

### 7. Like Button

Create a **Like** button and a number beside it.
Each click increases likes count.

---

### 8. Input Mirror

Create:

* input field
* paragraph

Whatever user types in input should appear live inside the paragraph.

---

### 9. Disable Button After Click

Create button **Submit**.
After clicking:

* button becomes disabled
* text changes to **Submitted**

---

### 10. Multiple Counters

Create:

* Counter A
* Counter B

Each counter has its own button and should update independently.

---

### 11. Password Toggle 👁

Create a password input and an eye icon button.
When clicking the eye:

* password becomes visible
* clicking again hides it

**Bonus:** change icon depending on state (open eye / closed eye).

---

## Requirement

Before solving each task, answer:

* How many states do I need?
* What type is each state? (boolean / number / string)
